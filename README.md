# QuizHub Frontend Demo

Frontend only: no database, API, localStorage or backend.

## Working parts
- Student Take Quiz page (student/quiz.html): the only page with JavaScript; quiz data and logic are inline

## Static parts
- Home, Login, Register, Student Dashboard, Student Result, Admin Dashboard, Admin Create Quiz

## Notes
- Student Dashboard and Result show fixed sample content
- Submitting a quiz opens the Result page, which does not read the score
